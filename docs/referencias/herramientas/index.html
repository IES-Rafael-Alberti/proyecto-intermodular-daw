    Herramientas del curso

    Recopilación de todas las herramientas vistas a lo largo del módulo de Proyecto Intermodular, organizadas por categorías según su función en el flujo de trabajo de un proyecto.

    1. Ideación y formación de equipos

    WebWhiteboard

    • Enlace: https://webwhiteboard.com
    • Descripción: Pizarra blanca colaborativa en línea para realizar lluvias de ideas de forma visual e instantánea. No requiere registro y permite trabajar en tiempo real con otros usuarios. Útil para las fases iniciales de brainstorming donde el equipo necesita volcar ideas de forma rápida y desordenada antes de filtrarlas.

    EduTeams

    • Enlace: https://eduteams.iiia.csic.es
    • Descripción: Plataforma desarrollada por el Instituto de Investigación en Inteligencia Artificial del CSIC que utiliza IA para formar equipos de estudiantes equilibrados. Tiene en cuenta factores como competencias, género y afinidad para maximizar el rendimiento colaborativo. Se utilizó al inicio del curso para formar los grupos de trabajo.

    2. Gestión de proyectos y metodología

    GitHub Projects

    • Enlace: https://docs.github.com/es/issues/planning-and-tracking-with-projects
    • Descripción: Herramienta integrada en GitHub para la planificación y seguimiento de tareas mediante tableros tipo Kanban. En el curso se utilizó como tablero SCRUM, definiendo campos como nombre de tarea, asignación, estado, estimación, prioridad, categoría (frontend, backend, BD) y sprint. Permite gestionar el Product Backlog y Sprint Backlog directamente vinculado al repositorio del proyecto.

    Toggl Track

    • Enlace: https://toggl.com/track
    • Descripción: Software de seguimiento de tiempo que permite registrar cuánto se dedica a cada tarea. Tiene extensión de navegador para iniciar y parar temporizadores fácilmente. En el curso se usó para medir el tiempo dedicado a cada issue/tarea del sprint, lo que permite mejorar las estimaciones futuras y entender la velocidad del equipo.

    SCRUM (metodología)

    • Enlace: https://www.scrum.org
    • Descripción: Metodología ágil utilizada como marco de trabajo del curso. Se implementó con sprints semanales, roles rotativos (Scrum Master, Product Owner, equipo de desarrollo) y ceremonias como Sprint Planning, Sprint Review y Sprint Retrospective. Toda la documentación de la metodología se mantuvo en la Wiki del repositorio de GitHub.

    3. Programación asistida por IA

    GitHub Copilot

    • Enlace: https://github.com/features/copilot
    • Descripción: Asistente de generación de código basado en IA integrado en el editor VS Code. Incluido en la mochila de Github para estudiantes.

    Claude Code

    • Enlace: https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/overview
    • Descripción: Agente de programación CLI de Anthropic que permite delegar tareas de desarrollo directamente desde la terminal.

    Gemini (Google)

    • Enlace: https://gemini.google.com
    • Descripción: Modelo de IA de Google utilizado en el curso para el entendimiento de proyectos existentes, usado a través de aistudio. Se usó con prompts específicos para analizar y comprender bases de código, combinándolo con el flujo de aprendizaje: intentar, buscar información, resolver dudas y cotejar resultados.

    Context7 (MCP Server)

    • Enlace: https://context7.com | GitHub
    • Descripción: Servidor MCP que proporciona documentación actualizada y específica por versión de cualquier librería o framework directamente en el prompt del agente de IA. Evita alucinaciones al dar acceso a documentación real y actualizada en lugar de depender de los datos de entrenamiento del modelo. Se puede usar añadiendo "usa context7" al prompt. Desarrollado por Upstash y gratuito.

    Chrome MCP (Browser MCP)

    • Enlace: https://chromedevtools.github.io/mcp | Docs
    • Descripción: Servidor MCP que permite a un agente de IA controlar el navegador Chrome de forma programática. En el curso se usó en combinación con Context7 para hacer demos de programación asistida, como crear una aplicación MERN completa con el agente navegando documentación en tiempo real.

    4. Investigación y comprensión con IA

    DeepWiki

    • Enlace: https://deepwiki.com
    • Descripción: Herramienta que convierte repositorios de GitHub en documentación interactiva generada por IA. Crea automáticamente diagramas, explicaciones y permite hacer preguntas contextuales sobre el código. Se introdujo en el curso para facilitar la comprensión de proyectos y dependencias.

    NotebookLM

    • Enlace: https://notebooklm.google
    • Descripción: Herramienta de investigación de Google que analiza documentos y los transforma en formatos comprensibles como resúmenes, podcasts o guías de estudio. En el curso se usó en combinación con Gitingest: se extraía el repositorio como texto y se cargaba en NotebookLM para analizarlo y generar resúmenes comprensibles del proyecto.

    Gitingest

    • Enlace: https://gitingest.com
    • Descripción: Convertidor de repositorios Git a texto plano optimizado para ser procesado por modelos de lenguaje. Facilita la preparación de una base de código completa para su análisis con herramientas de IA como NotebookLM o cualquier LLM.

    Deep Research (LLM)

    • Descripción: Funcionalidad disponible en varios LLM (como ChatGPT, Gemini o Claude) que permite realizar investigaciones exhaustivas sobre un tema, analizando múltiples fuentes y sintetizando la información. En el curso se usó para validar las ideas de proyecto propuestas por los equipos, comprobando viabilidad y antecedentes.

    5. Testing y calidad

    Maestro

    • Enlace: https://maestro.dev
    • Descripción: Framework de automatización de pruebas visuales de interfaz de usuario para aplicaciones web y móviles. Permite crear tests en formato YAML de forma sencilla, sin necesidad de escribir código complejo. Es de código abierto y se integra con GitHub Actions para ejecutar pruebas automáticas en cada push o PR. En el curso se usó para el testing de historias de usuario y la optimización de la experiencia de usuario.

    React Doctor

    • Enlace: https://www.react.doctor
    • Descripción: Herramienta CLI que diagnostica problemas de rendimiento, antipatrones de seguridad y oportunidades de optimización en proyectos React mediante análisis estático. Proporciona puntuaciones y recomendaciones accionables para mejorar la calidad del código.

    6. Seguridad

    Trivy

    • Enlace: https://trivy.dev
    • Descripción: Escáner de seguridad de código abierto que detecta vulnerabilidades en dependencias, secretos expuestos y configuraciones incorrectas. Funciona tanto en repositorios locales como en imágenes Docker. Se integra con GitHub Actions y dispone de servidor MCP. Comando básico: trivy fs --scanners vuln,secret,misconfig /path/to/myproject.

    Snyk

    • Enlace: https://snyk.io
    • Descripción: Plataforma de seguridad orientada a empresas que, además de escanear vulnerabilidades en dependencias como Trivy, analiza el código en tiempo real dentro del IDE. Ofrece integración con flujos de CI/CD y herramientas de desarrollo.

    Dependabot (GitHub)

    • Enlace: https://docs.github.com/es/code-security/dependabot
    • Descripción: Herramienta integrada en GitHub que escanea automáticamente las dependencias del repositorio. Cuando detecta una vulnerabilidad conocida, crea automáticamente un Pull Request para actualizar la dependencia afectada. Activación sencilla desde la configuración de seguridad del repositorio.

    Helmet.js

    • Enlace: https://helmetjs.github.io
    • Descripción: Middleware de seguridad para Express que configura automáticamente 13 cabeceras HTTP de seguridad en las respuestas del servidor. Instalación sencilla con npm install helmet y uso básico con app.use(helmet()).

    CORS (npm)

    • Enlace: https://www.npmjs.com/package/cors
    • Descripción: Middleware para Express que gestiona el Cross-Origin Resource Sharing, controlando qué dominios pueden acceder a tu API. Esencial para la comunicación segura entre frontend y backend en aplicaciones MERN.

    express-rate-limit

    • Enlace: https://www.npmjs.com/package/express-rate-limit
    • Descripción: Middleware que limita el número de solicitudes que un cliente puede hacer a la API en un periodo de tiempo. Protege contra ataques de fuerza bruta y abuso de la API.

    Buenas prácticas: SECURITY.md y .env

    • SECURITY.md: Archivo que se incluye en el repositorio con instrucciones sobre cómo reportar problemas de seguridad. GitHub lo muestra automáticamente cuando alguien crea un issue. Ejemplo: Electron. En producción, el equivalente es SECURITY.txt.
    • .env y .env.example: El archivo .env contiene claves secretas y NUNCA debe subirse al repositorio (incluirlo en .gitignore). Se crea un .env.example bien documentado con las variables necesarias pero sin valores reales, para que otros desarrolladores sepan qué configurar.

    react2shell (ejemplo CVE)

    • Enlace: https://react2shell.com
    • Descripción: Ejemplo de vulnerabilidad real (CVE) en React que se estudió en el curso como caso práctico de por qué la seguridad es innegociable. Demuestra cómo una vulnerabilidad en un framework popular puede comprometer un sistema completo.

    7. Despliegue e infraestructura

    Pinokio

    • Enlace: https://pinokio.co
    • Descripción: Navegador de automatización que permite instalar y ejecutar aplicaciones de IA de código abierto en local con un solo clic, sin necesidad de conocimientos técnicos de configuración. Útil para probar herramientas de IA rápidamente.

    GitHub Actions

    • Enlace: https://docs.github.com/es/actions
    • Descripción: Plataforma de CI/CD integrada en GitHub que permite automatizar flujos de trabajo como la ejecución de tests, despliegues y análisis de seguridad. En el curso se usó para automatizar las pruebas de Maestro y otros procesos del pipeline de desarrollo.

    8. Documentación y profesionalización

    Manfred - Developer Career Report

    • Enlace: https://www.getmanfred.com/developer-career-report
    • Descripción: Informe anual sobre el ecosistema tecnológico español con datos sobre empleos, tecnologías, salarios y tendencias del sector. Se usó en el curso como referencia para entender el mercado laboral y orientar las decisiones profesionales.

    entire.io

    • Enlace: https://entire.io
    • Descripción: Plataforma de desarrollo que se integra con flujos Git para capturar automáticamente las sesiones de agentes de IA en cada push, unificando el código con su contexto y razonamiento. Mencionada en el curso como herramienta potencialmente interesante para documentar el proceso de desarrollo asistido por IA.

    WebMCP (Browser MCP)

    • Enlace: https://browsermcp.io
    • Descripción: Protocolo que permite a los sitios web exponer funciones JavaScript como herramientas invocables por agentes de IA, eliminando la necesidad de captura de pantallas o interpretación del DOM.
