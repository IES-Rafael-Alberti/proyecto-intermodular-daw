## Flujo de trabajo propuesto

1 - Convertir tarea en Issue

2 - Crear rama para el Issue

3 - Arrancar timer


4 - Trabajamos en la tarea

5.1 - Si no está terminada, ponemos un comentario en el issue explicando nuestro trabajo


5.2 - Si está terminada, ponemos un comentario explicativo, cerramos el issue y creamos un PR si es necesario

6 - Paramos el timer

## Automatiza con GitHub Actions

```yaml
name: Run Maestro Web Tests

on:
  workflow_dispatch:

  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  maestro-web:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout code
        uses: actions/checkout@v3

      - name: Setup Java
        uses: actions/setup-java@v4
        with:
          distribution: 'temurin'
          java-version: '17'

      - name: Setup Chrome
        uses: browser-actions/setup-chrome@v2
        with:
          chrome-version: stable
          install-dependencies: true

      - name: Install Maestro
        run: |
          curl -fsSL "https://get.maestro.mobile.dev" | bash
          echo "$HOME/.maestro/bin" >> $GITHUB_PATH

      - name: Setup Xvfb for headless Chrome
        run: |
          sudo apt-get update
          sudo apt-get install -y xvfb
          sudo Xvfb :99 -screen 0 1920x1080x24 > /dev/null 2>&1 &
          sleep 2

      - name: Run Maestro Web Tests
        uses: nick-fields/retry@v3
        with:
          timeout_minutes: 5
          max_attempts: 2
          retry_on: error
          command: |
            export PATH="$HOME/.maestro/bin:$PATH"
            maestro test .maestro/ --format junit --output report.xml
        env:
          MAESTRO_CLI_NO_ANALYTICS: "1"
          DISPLAY: ":99"

      - name: Upload Test Report
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: maestro-test-report
          path: |
            report.xml
            ~/.maestro/tests/**/*
          if-no-files-found: warn
```

## CORS

CORS (Cross-Origin Resource Sharing) es un mecanismo de seguridad del navegador que controla qué dominios pueden acceder a tu API


`npm install cors`


Permitir CORS para todos los orígenes (solo para desarrollo)

```
const express = require('express');
const cors = require('cors');

const app = express();

// Permitir CORS para todas las rutas y orígenes
app.use(cors());

app.get('/api/data', (req, res) => {
  res.json({ data: 'información pública' });
});
```


Configuración segura (Producción)

```
const cors = require('cors');

const corsOptions = {
  origin: ['http://localhost:3000', 'https://miapp.com'],
  methods: ['GET', 'POST', 'PUT', 'DELETE'],
  allowedHeaders: ['Content-Type', 'Authorization'],
  credentials: true,  // Permitir cookies/autenticación
  optionsSuccessStatus: 200
};

app.use(cors(corsOptions));
```


## Rate limiting

Estrategia de seguridad que limita el número de solicitudes que un cliente puede hacer en un período de tiempo


`npm install express-rate-limit`


Implementación básica: bloquear solicitudes excesivas

```
const rateLimit = require('express-rate-limit');

// Crear limitador: máx 100 solicitudes por 15 minutos
const limiter = rateLimit({
  windowMs: 15 * 60 * 1000,    // Ventana temporal: 15 minutos
  max: 100,                      // Máximo de solicitudes
  message: 'Demasiadas solicitudes, intenta más tarde',
  standardHeaders: true,         // Headers recomendados por IETF
  legacyHeaders: false           // Desactivar headers antiguos
});

// Aplicar a todas las rutas
app.use(limiter);

app.get('/api/data', (req, res) => {
  res.json({ msg: 'Solicitud exitosa' });
});
```


## Helmet.js

Middleware de seguridad para Express que automáticamente configura 13 headers HTTP de seguridad en las respuestas de tu servidor


`npm install helmet`


Ejemplo de implementación básica

```
// server.js
const express = require('express');
const helmet = require('helmet');

const app = express();

// Usar Helmet en todas las rutas
app.use(helmet());

app.get('/', (req, res) => {
  res.json({ msg: 'Tu API está protegida con Helmet' });
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`Servidor ejecutándose en puerto ${PORT}`);
});
```
